# Oxidify 0.3.7

Podcast progress, playlist editing, and everyday controls behave more consistently.

## Five improvements

- **Continue podcast episodes.** Play on an unfinished episode resumes from the saved place shown in its row. Finished episodes start over. An already active episode keeps its live position. Episodes inside playlists retain the playlist and its displayed queue order.
- **Edit the playlist you are looking at.** Remove from this playlist stays available while sorted or filtered. Playback follows the visible rows, while positional moves remain limited to the original unfiltered order. Missing dates no longer misalign the table.
- **Find the destination without losing the menu.** Clicking or scrolling inside Add to playlist keeps it open. Clearing its filter restores the full scrollable list, and choosing a destination closes it normally.
- **Respect the playback device.** Devices that reject remote volume changes show disabled volume and mute controls; keyboard, media-control, and mini-player volume actions respect the same capability. One-track and one-episode remote requests use the supported request shape.
- **Keep navigation predictable.** Clearing the search field stays on the current page. Typing a new query opens Search. Shift shortcuts keep their intended action, and text fields retain arrow-key cursor movement and selection.

## Reliability

- Automatic replacement of the local Spotify engine keeps the last volume heard instead of restoring the launch volume. Explicit new settings still take precedence.
- Settings files saved as UTF-8 with a leading byte order mark keep their preferences.
- Release checks and all platform builds use one validated source commit. Archive contents, required notices, architecture, checksums, and build provenance are checked before a draft is produced.

Podcast resume requires supported Spotify playback. Alternate local audio retains its existing account routing and does not support podcast episodes. This update does not add Spotify playback capabilities to Free accounts.

## Downloads

Windows installers and portable ZIPs are available for x64 and ARM64. The macOS DMG contains a universal app for Apple Silicon and Intel. Linux archives are available for x64 and ARM64. `checksums.txt` lists SHA-256 hashes; the provenance file identifies the source commit and build run.

Automated tests run on Linux, macOS, and Windows. Linux binaries, the macOS runner's native slice, and the Windows x64 installer receive runtime checks. Windows ARM64 and the other macOS slice are compiled and inspected, not run on native hardware. Live Spotify-account playback was not exercised for this release.

Windows SmartScreen or macOS Gatekeeper may warn about an unsigned download. See the [installation guide](https://master0ffate.github.io/oxidify/download/) for platform instructions.
