# Oxidify 0.8.1

A small release that makes long playlists lighter on the processor. Nothing changes in how Oxidify looks or what it does; frames that used to copy a whole playlist now share it.

## Changed

- **Sorted and filtered playlists cost far less per frame.** Clicking a column heading or typing in a playlist's filter shows a view of the list, and the player used to copy every song's address in that view twice on every frame, once for the rows and once for the big play button. On a playlist of ten thousand songs that was most of the frame. The view is now shared, so a frame only counts a reference and a play copies just what it needs. In the frame benchmark the sorted page went from about 1.6 ms a frame to about 0.13 ms, and the plain playlist page from about 0.32 ms to about 0.13 ms.
- **The playlist header stops re-counting.** The total playing time and the choice to show the Date added column were worked out from every row on every frame. They are kept with the rows now and updated as pages arrive.
- **Fewer repeated searches in lists.** The Add to playlist sheet looked up each playlist's place among your recent ones by walking that list for every comparison, and checked each pin the same way; both are direct lookups now. Removing songs from a playlist, checking whether a playlist already holds a song, and loading a long playlist in alternate playback each compared every row against every song; each now gathers what it is looking for once.

## Downloads

Windows installers and portable ZIPs are available for x64 and ARM64. The macOS DMG contains a universal app for Apple Silicon and Intel. Linux archives are available for x64 and ARM64. `checksums.txt` lists SHA-256 hashes; the provenance file identifies the source commit and build run.

Automated tests run on Linux, macOS, and Windows, with new tests for the row totals, the sheet's order, and the alternate session's loading. The frame benchmark was run before and after on Linux; macOS and Windows were compiled and tested by CI, not driven by hand.

Windows SmartScreen or macOS Gatekeeper may warn about an unsigned download. See the [installation guide](https://master0ffate.github.io/oxidify/download/) for platform instructions.
