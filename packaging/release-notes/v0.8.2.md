# Oxidify 0.8.2

A small fix: the equalizer now works in alternate playback.

## Fixed

- **The equalizer shapes alternate audio.** The ten bands, the preamp, balance and mono used to change only Spotify playback; with alternate playback on, moving a slider did nothing. The same filters now run over the audio decoded on this computer, whatever its sample rate, so the graph in Settings matches what you hear.

## Downloads

Windows installers and portable ZIPs are available for x64 and ARM64. The macOS DMG contains a universal app for Apple Silicon and Intel. Linux archives are available for x64 and ARM64. `checksums.txt` lists SHA-256 hashes; the provenance file identifies the source commit and build run.

Automated tests run on Linux, macOS, and Windows, with a new test that a band lands on its frequency at a 48 kHz mono source. Only the filter maths and the existing suite were run, on Linux; nobody has listened to alternate playback through the equalizer yet, and macOS and Windows were compiled and tested by CI, not driven by hand.

Windows SmartScreen or macOS Gatekeeper may warn about an unsigned download. See the [installation guide](https://master0ffate.github.io/oxidify/download/) for platform instructions.
