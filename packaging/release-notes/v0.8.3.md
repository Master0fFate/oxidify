# Oxidify 0.8.3

Local playback gets the most love this round: the progress bar no longer
races ahead of the music, big playlists stop refetching every time you open
them, and a pile of smaller playback and reliability fixes ride along.

## Fixed

- **The local playback clock keeps real time again.** On free/alternate
  playback the progress bar ran at double speed and hit the end before the
  song did; clicking the bar realigned it. The position now interpolates from
  the moment it was last reported, so the bar and the audio agree.

- **A full playlist stays full.** Reopening a fully cached playlist used to
  throw its rows away if the snapshot didn't match, then rebuild the whole
  list from the API, which is slow for a thousand-song playlist. It now keeps
  the cached rows when the live track count still matches, so an unchanged
  playlist opens instantly from disk.

- **Local playback edges.** Seeking, gapless skipping onto a ready prefetch,
  repeating a lone track on Next, starting a paused track, and seeking before
  the decoder starts now behave. The equalizer runs over local audio, and
  yt-dlp cookie and proxy handling no longer leaks between runs.

- **Remote control is scoped to the account that started the app.** The
  Raycast, Stream Deck, and `oxidify` verbs now carry a user key, so another
  account on the same machine cannot drive playback. Read-only verbs still
  answer anyone.

- **Reliability.** A token refresh can no longer resurrect a deleted sign-in,
  signing out resets the premium flag, device names with accented characters
  decode correctly, and a crafted skin archive no longer forces a large
  allocation.

## Downloads

Windows installers and portable ZIPs are available for x64 and ARM64. The
macOS DMG contains a universal app for Apple Silicon and Intel. Linux
archives are available for x64 and ARM64. `checksums.txt` lists SHA-256
hashes; the provenance file identifies the source commit and build run.

Automated tests run on Linux, macOS, and Windows. The changes were built and
tested on Windows only; Linux and macOS are compiled and tested by CI, not
driven by hand.

Windows SmartScreen or macOS Gatekeeper may warn about an unsigned download.
See the [installation guide](https://master0ffate.github.io/oxidify/download/)
for platform instructions.
