# Oxidify 0.6.1

Likes and playlist changes work again for every account, and the Add to playlist sheet is the one Spotify's client has, Liked Songs row included.

## Fixed

- **Liking a song and adding it to a playlist work for every account.** Library writes went only to Spotify's single library endpoint, which some apps and accounts refuse, so a like, an unlike or a follow could fail with nothing to show for it. The client now falls back to the classic endpoint of each kind, songs, albums, artists, podcasts, episodes and playlists, the moment the single endpoint refuses, and goes there first from then on. Library checks take the same road.
- **Liked Songs can be left again.** The sheet the check opens listed only playlists, so a song liked by mistake had nowhere to be unliked from. Liked Songs is now its first row.

## Changed

- **The Add to playlist sheet matches Spotify's.** A search, New playlist, then Liked Songs and the playlists you can edit, the ones already holding the song under Saved in with a check and the rest under Recently updated with an empty circle, each with its cover, its pin and its count. Click rows to tick or untick them, and Done applies every change at once; Cancel drops them. Enter in the search still adds to the first match straight away. The same sheet sits behind Add to playlist in every song's menu.

## Downloads

Windows installers and portable ZIPs are available for x64 and ARM64. The macOS DMG contains a universal app for Apple Silicon and Intel. Linux archives are available for x64 and ARM64. `checksums.txt` lists SHA-256 hashes; the provenance file identifies the source commit and build run.

Automated tests run on Linux, macOS, and Windows, including a headless render of the sheet and tests for the endpoint fallback's grouping and for what Done applies. The interface was exercised on Linux in demo mode; macOS and Windows were compiled and tested by CI, not driven by hand. The fallback was not exercised against a live Spotify account from the build machine.

Windows SmartScreen or macOS Gatekeeper may warn about an unsigned download. See the [installation guide](https://master0ffate.github.io/oxidify/download/) for platform instructions.
